# 🎨 CSS: Kaskádové styly (Cascading Style Sheets)

Zatímco jazyk HTML tvoří pevnou kostru a dává obsahu sémantický význam, CSS se stará o to, jak tento obsah **vypadá**. Pomocí kaskádových stylů tak vdechnete webu život: nastavíte barvy, velikosti písma, animace a celý layout (rozložení stránky pro mobily i počítače).

## Obsah této sekce

1. **[Základy, koncepce a selektory](doc/01-zaklady-css.md)**
   * Kde se styly vůbec berou? Jak vybrat správný kus HTML kódu pomocí id, tečky nebo rodiče. Princip kaskády.
2. **[Box Model, barvy a jednotky](doc/02-box-model-barvy.md)**
   * Nejdůležitější kapitola pro pochopení marginů, paddingů a záludností šířky na straně.
3. **[Layout a pozicování (Flexbox vs. Grid)](doc/03-layout.md)**
   * Jak donutit dva prvky být vedle sebe, jak věci centrovat a vysvětlení moderního standardu flexbox.  
4. **[Úvod do UI/UX a Responzivita](doc/04-ui-ux.md)**
   * Že to umíme napsat, neznamená, že se to dá číst. Best practices z pohledu designu, typografie a mobilní verze.
