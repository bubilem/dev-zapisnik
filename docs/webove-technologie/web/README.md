# Další problematiky ohledně webu

Tato sekce se věnuje tématům, která přesahují samotné HTML, CSS a JavaScript, ale jsou pro tvorbu kvalitních webových stránek neméně důležitá. Dozvíte se, jak psát weby přístupné pro všechny uživatele a jak zajistit, aby vás vyhledávače správně indexovaly a zobrazovaly ve výsledcích hledání.

## Obsah této sekce

1. **[Přístupnost webových stránek (a11y)](doc/pristupnost.md)**
   * Co je přístupnost a proč na ní záleží.
   * Standardy WCAG a kategorie postižení, která přístupnost řeší.
   * Praktické techniky: sémantické HTML, ARIA atributy, kontrast, klávesnicová navigace a formuláře.

2. **[SEO – Optimalizace pro vyhledávače](doc/seo.md)**
   * Jak fungují vyhledávače a co ovlivňuje pořadí ve výsledcích.
   * On-page SEO: meta tagy, struktura nadpisů, URL, strukturovaná data.
   * Technické SEO: výkon stránky, mobilní zobrazení, sitemap a robots.txt.

3. **[Výkon a efektivita načítání](doc/vykon.md)**
   * Proč je rychlost webu důležitá pro UX a SEO.
   * Optimalizace obrázků (formáty, lazy loading, responzivita).
   * Minifikace a komprese kódu, asynchronní načítání JavaScriptu (`defer`, `async`).

4. **[Nástroje pro webové vývojáře](doc/nastroje.md)**
   * Přehled užitečných nástrojů pro tvorbu, ladění a měření webu.
   * Nástroje v prohlížeči (DevTools, Lighthouse), generátory (Favicon, QR, CSS).
   * Pomocníci pro design, barvy a analytické nástroje (Google Analytics).

5. **[Webová komunikace a protokoly](doc/network.md)**
   * Architektura klient-server.
   * HTTP požadavek (Request), metody a hlavičky.
   * HTTP odpověď (Response) a stavové kódy (200, 404, 500).
   * Zabezpečení komunikace pomocí HTTPS a certifikátů.
