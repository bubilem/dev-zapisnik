# Jazyk HTML (HyperText Markup Language)

Vítejte v sekci věnované základům i pokročilým technikám jazyka HTML. HTML tvoří základní kostru každé webové stránky a určuje její strukturu a význam obsahu.

## Obsah této sekce

Tato sekce je rozdělena do tří na sebe navazujících kapitol:

1. **[Základy, pravidla a DOM](doc/01-zaklady.md)**
   * Dozvíte se, jak vypadá základní kostra dokumentu, co je to značka (tag), jak se značky vnořují a jak prohlížeč vytváří z HTML takzvaný DOM (Document Object Model).
2. **[Přehled používaných značek a sémantika](doc/02-prehled-znacek.md)**
   * Kompletní přehled od nadpisů a odstavců přes tabulky a formuláře až po moderní sémantické značky (header, nav, article), které pomáhají čitelnosti kódu.
3. **[Přístupnost, SEO a pokročilé techniky](doc/03-pokrocile-techniky.md)**
   * Zde se podíváme pod povrch. Zjistíte, jak psát weby, které milují vyhledávače (SEO, Open Graph data) i čtečky obrazovky (přístupnost/a11y), a k čemu slouží `data-*` atributy.
4. **[Tipy, triky a chybějící střípky](doc/04-tipy-a-triky.md)**
   * Dozvíte se důležité drobnosti pro praxi: znakové entity, jak odeslat data z formuláře (GET a POST), logiku absolutních a relativních cest nebo kdy nasadit interaktivní značky (`iframe`, `svg`, `picture`).
