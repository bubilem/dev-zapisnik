# Kompetence pro webové technologie

Tento repozitář slouží jako centrální znalostní báze a průvodce pro výuku webových technologií. Obsahuje studijní materiály, dokumentaci a praktická cvičení, která pokrývají cestu od úplných základů až po moderní JavaScript.

---

## Obsah kurzu

Dokumentace je rozdělena do logických celků:

## Požadavky a Nástroje

Pro práci s těmito materiály doporučujeme:

1. **[Visual Studio Code](https://code.visualstudio.com/)** – Editor kódu.
2. **Rozšíření Live Server** – Pro okamžitý náhled změn v prohlížeči.
3. **Moderní prohlížeč** – Chrome, Firefox, Edge nebo Safari (pro vývojářské nástroje DevTools).

## Jak začít

Pro stažení materiálů do počítače použijte git:

```bash
git clone https://github.com/bubilem/webove-technologie.git
cd webove-technologie
```

Nebo si stáhněte repozitář jako **ZIP** archiv přes tlačítko *Code* -> *Download ZIP*.
