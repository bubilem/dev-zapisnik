# Webové technologie

Tato sekce shromažďuje výukové a referenční materiály týkající se návrhu a tvorby webových aplikací. Věnujeme se zde primárně frontendu, a postupujeme od samotných základů struktury až po design.

## Obsah

Oblast webových technologií je aktuálně rozdělena na tyto hlavní okruhy:

*   **[HTML (HyperText Markup Language)](html/README.md)**  
    Architektura webových stránek. HTML značky, DOM, moderní sémantika (hlavičky, články), pravidla pro psaní čistého kódu, přístupnost (A11y) a SEO optimalizace.
*   **[CSS (Cascading Style Sheets)](css/README.md)**  
    Design webů na profi úrovni. Kaskáda, Box model, barvy, tvorba moderních layoutů (Flexbox a Grid), responzivita (Mobile First) a základy dobrého UI/UX.
*   **[Kompetence](kompetence/README.md)**  
    Přehled požadovaných teoretických i praktických dovedností, které by měl student / vývojář ovládat.
